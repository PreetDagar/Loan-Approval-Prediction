# Loan Approval Prediction System

## Overview

This project predicts whether a loan application is likely to be approved using machine learning.

## Project Files

* `loan_approval_prediction.ipynb` — notebook for model development and analysis.
* `loan_approval_dataset.xlsx` — loan application dataset.
* `loan_predictions_final.xlsx` and `loan_predictions_final2.csv` — prediction results.
* `PREDECTION_DASHBOARD.pbix` and `loan_approval_dashboard.pbix` — Power BI dashboard files.

## Model Evaluation

The project can be documented with metrics such as:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC
* Confusion matrix
* Classification report

## Tools Used

* Python
* Jupyter Notebook
* Pandas and machine learning libraries
* Power BI

## How to Run

1. Download or clone this repository.
2. Install the dependencies required by the notebook.
3. Open `loan_approval_prediction.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
